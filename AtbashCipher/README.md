# Лабораторна робота №5: Шифрування Атбаш

## Опис проекту

Програма для шифрування та дешифрування тексту з використанням алгоритмів:
- **Простий Атбаш** - шифр простої заміни (перша літера ↔ остання)
- **Атбаш з ключовим словом** - шифр заміни з використанням ключа

## Вимоги

- Visual Studio Community 2022
- .NET Framework 4.8
- Платформа: Windows
- C++/CLI з підтримкою Windows Forms

## Функціональність

### 1. Простий Атбаш
- Шифрування тексту простим Атбашем
- Дешифрування тексту
- Підтримка англійських та українських літер

### 2. Атбаш з ключем
- Встановлення ключового слова (прізвище без повторів)
- Генерація алфавіту заміни
- Шифрування/дешифрування з використанням ключа

### 3. Робота з файлами
- Завантаження текстових файлів
- Шифрування вмісту файлу
- Дешифрування вмісту файлу
- Збереження результату

## Як використовувати

### Відкриття проекту

1. Відкрийте Visual Studio 2022
2. File → Open → Project/Solution
3. Виберіть файл `AtbashCipher.sln`
4. Натисніть F5 для запуску

### Робота з програмою

#### Вкладка "Простий Атбаш"
1. Введіть текст у поле "Вхідний текст"
2. Натисніть "Зашифрувати" або "Розшифрувати"
3. Результат з'явиться в полі "Результат"

#### Вкладка "Атбаш з ключем"
1. Введіть ключове слово (прізвище) у відповідне поле
2. Натисніть "Встановити ключ"
3. Перегляньте згенерований алфавіт заміни
4. Введіть текст для шифрування/дешифрування
5. Натисніть відповідну кнопку

#### Вкладка "Робота з файлами"
1. Введіть ключове слово (опціонально)
2. Натисніть "Завантажити файл" та виберіть текстовий файл
3. Натисніть "Зашифрувати" або "Розшифрувати"
4. Результат з'явиться в полі нижче
5. Натисніть "Зберегти результат" для збереження

## Технічні деталі

### Алгоритм простого Атбаш

Для англійського алфавіту:
- A ↔ Z, B ↔ Y, C ↔ X, ...

Для українського алфавіту:
- А ↔ Я, Б ↔ Ю, В ↔ Ь, ...

### Алгоритм Атбаш з ключем

1. Створюється ключове слово без повторів літер
2. Ключ розміщується на початку алфавіту заміни
3. Решта літер додаються в алфавітному порядку
4. Кожна літера вихідного алфавіту замінюється відповідною літерою з алфавіту заміни
