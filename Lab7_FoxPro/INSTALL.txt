ІНСТРУКЦІЯ ПО ВСТАНОВЛЕННЮ ТА ЗАПУСКУ
Лабораторна робота №7
Visual FoxPro 9.0
=========================================

КРОК 1: ВИМОГИ
-----------------
- Microsoft Visual FoxPro 9.0 (або новіша версія)
- ОС Windows XP/7/8/10/11
- 50 МБ вільного місця

КРОК 2: ВСТАНОВЛЕННЯ Visual FoxPro 9
-------------------------------------
1. Завантажте Visual FoxPro 9.0 SP2
2. Запустіть інсталятор
3. Слідуйте інструкціям майстра встановлення
4. Виберіть "Complete" (повне встановлення)

КРОК 3: НАЛАШТУВАННЯ ПРОЕКТУ
-----------------------------
1. Скопіюйте папку Lab7_FoxPro на диск C:\
   Шлях: C:\Lab7_FoxPro\

2. Запустіть Visual FoxPro 9

3. Встановіть робочу директорію:
   File → Set Default Directory
   Виберіть: C:\Lab7_FoxPro\

КРОК 4: СТВОРЕННЯ БАЗИ ДАНИХ
-----------------------------
У командному вікні Visual FoxPro введіть:

   CD "C:\Lab7_FoxPro"
   DO data\create_database.prg

Повинно з'явитися повідомлення:
"База даних lab_7_db успішно створена!"

КРОК 5: ЗАПУСК ПРОГРАМИ
------------------------
Варіант А - через PRG файл:

   DO main.prg

Варіант Б - запуск головної форми:

   DO FORM forms\mainform.prg

КРОК 6: РОБОТА З ПРОГРАМОЮ
---------------------------
1. З'явиться головна форма з меню
2. Виберіть: SEARCH → Послідовний пошук
3. У формі пошуку:
   - Виберіть поле для пошуку
   - Введіть текст
   - Натисніть "Знайти"

ПРИКЛАД ТЕСТУВАННЯ:
------------------
1. Поле: "lastname - Прізвище"
2. Текст: "Мусаєв"
3. Натисніть "Знайти"
4. Результат: запис з прізвищем Мусаєв

TROUBLESHOOTING
---------------
Проблема: "File not found: data\lab_7_db.dbc"
Рішення: Запустіть КРОК 4 (створення БД)

Проблема: Кирилиця не відображається
Рішення: У командному вікні:
   SET CODEPAGE TO 1251

Проблема: Форма не відкривається
Рішення: Перевірте шлях до файлів:
   ? CURDIR()  && Показати поточну директорію
