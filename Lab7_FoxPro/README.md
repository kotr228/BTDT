## Функціональність програми

### 1. Головне меню

Програма має головне меню з двома пунктами:

#### FILE
- **Exit** - вихід з програми (Ctrl+Q)

#### SEARCH
- **Послідовний пошук** - відкриття форми пошуку (Ctrl+F)

### 2. Форма послідовного пошуку

Форма містить наступні компоненти:

#### Компоненти інтерфейсу:
- **TextBox** - поле для введення пошукового запиту
- **ComboBox** - вибір поля для пошуку:
  - Прізвище
  - Ім'я
  - По батькові
  - Адреса
  - Телефон
  - Email
- **CheckBox "Враховувати регістр"** - регістрозалежний пошук
- **CheckBox "Шукати з початку"** - починати пошук з початку таблиці
- **Grid** - відображення результатів пошуку

#### Кнопки керування:
- **"Знайти"** - пошук першого збігу
- **"Знайти далі"** - пошук наступного збігу
- **"Очистити"** - очищення поля пошуку
- **"Показати всі"** - показати всі записи
- **"Закрити"** - закрити форму

## Алгоритм послідовного пошуку

### Принцип роботи:

1. **Отримання параметрів пошуку:**
   - Пошуковий запит з TextBox
   - Вибране поле з ComboBox
   - Налаштування регістру та позиції

2. **Послідовний перегляд записів:**
   ```foxpro
   SCAN
       lcFieldValue = EVALUATE("customer." + tcFieldName)
       IF tcSearchValue $ lcFieldValue
           * Запис знайдено!
           EXIT
       ENDIF
   ENDSCAN
   ```

3. **Відображення результату:**
   - При знаходженні - позиціювання на запис у Grid
   - Якщо не знайдено - повідомлення користувачу

4. **Пошук наступного:**
   - Продовжує пошук з поточної позиції
   - Дозволяє знайти всі збіги по черзі

## Особливості реалізації

### 1. Послідовний пошук (Sequential Search)

- Алгоритм переглядає записи по черзі від початку до кінця
- Складність: O(n), де n - кількість записів
- Переваги: простота реалізації, пошук по будь-якому полю
- Недоліки: повільний для великих таблиць

### 2. Пошук підрядка

Використовується оператор `$` (contains):
```foxpro
IF "Іва" $ "Іваненко"  && Повертає .T.
```

### 3. Регістронезалежний пошук

```foxpro
IF UPPER("іваненко") $ UPPER("ІВАНЕНКО")  && Повертає .T.
```

## Налаштування та розширення

### Додавання нових полів для пошуку:

У файлі `forms\searchform.prg`, метод `Init`:
```foxpro
THISFORM.cboField.AddItem("newfield - Нове поле")
```

### Зміна швидкості пошуку:

Для великих таблиць можна використовувати індекси:
```foxpro
INDEX ON UPPER(lastname) TAG lastname
SET ORDER TO lastname
SEEK UPPER(lcSearchValue)
```

### Додавання фільтрації:

```foxpro
SET FILTER TO UPPER(lastname) $ UPPER(lcSearchValue)
GO TOP
```

## Коди команд Visual FoxPro

### Робота з таблицями:
```foxpro
USE customer              && Відкрити таблицю
GO TOP                    && Перейти на перший запис
GO BOTTOM                 && Перейти на останній запис
SKIP                      && Наступний запис
SKIP -1                   && Попередній запис
SCAN ... ENDSCAN          && Цикл по всіх записах
LOCATE FOR condition      && Пошук запису за умовою
CONTINUE                  && Продовжити пошук
EOF()                     && Кінець файлу?
RECNO()                   && Номер поточного запису
RECCOUNT()                && Загальна кількість записів
```

### Функції для роботи з рядками:
```foxpro
ALLTRIM()                 && Видалити пробіли з обох боків
UPPER()                   && Перетворити в верхній регістр
LOWER()                   && Перетворити в нижній регістр
LEFT(cString, nChars)     && Ліві символи
RIGHT(cString, nChars)    && Праві символи
SUBSTR(cString, nStart, nLength)  && Підрядок
LEN(cString)              && Довжина рядка
AT(cSearch, cString)      && Позиція підрядка
$ (оператор)              && Перевірка наявності підрядка
```

## Troubleshooting (Вирішення проблем)

### Проблема: "File not found: data\lab_7_db.dbc"

**Рішення:**
1. Запустіть `data\create_database.prg`
2. Або змініть шлях у `main.prg`

### Проблема: "Variable 'OFORMREF' is not found"

**Рішення:**
- Переконайтеся, що меню завантажується правильно
- Перевірте код у методі `Init` головної форми

### Проблема: Кирилиця відображається некоректно

**Рішення:**
```foxpro
SET CODEPAGE TO 1251  && Windows Cyrillic
```

### Проблема: Grid не оновлюється

**Рішення:**
```foxpro
THISFORM.grdCustomer.Refresh()
```
