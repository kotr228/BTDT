# Лабораторна робота №7 - Visual FoxPro

## Опис

Базова лабораторна робота з Visual FoxPro - створення простої бази даних та робота з даними за допомогою команд.

## Мета роботи

- Навчитися створювати базу даних у Visual FoxPro
- Освоїти базові команди для роботи з таблицями
- Навчитися додавати, переглядати та фільтрувати дані

## Структура проекту

- `create_simple_db.prg` - скрипт створення простої БД
- `work_with_data.prg` - скрипт для роботи з даними
- `README.md` - документація

## База даних TktDB_Simple

Проста база даних для системи залізничних квитків містить 4 таблиці:

### 1. Stations - Залізничні станції
- `stat_id` - ID станції (автоінкремент)
- `name` - назва станції
- `city` - місто
- `region` - область

**Дані:** 8 станцій (Київ, Львів, Одеса, Харків, Дніпро, Запоріжжя, Вінниця, Полтава)

### 2. CarTypes - Типи вагонів
- `ctype_id` - ID типу (автоінкремент)
- `type_name` - назва типу
- `base_cost` - базова вартість
- `capacity` - місткість (кількість місць)

**Дані:** 5 типів (Плацкарт, Купе, Люкс, Сидячий 1-клас, Сидячий 2-клас)

### 3. Passengers - Пасажири
- `pass_id` - ID пасажира (автоінкремент)
- `lname` - прізвище
- `fname` - ім'я
- `pname` - по батькові
- `phone` - телефон
- `email` - електронна пошта

**Дані:** 7 пасажирів (відомі українські письменники)

### 4. Routes - Маршрути
- `route_id` - ID маршруту (автоінкремент)
- `route_name` - назва маршруту
- `orig_station` - станція відправлення
- `dest_station` - станція прибуття
- `distance` - відстань у кілометрах

**Дані:** 5 маршрутів між містами України

## Використання

### Крок 1: Створення бази даних

У Visual FoxPro Command Window виконайте:
```foxpro
DO create_simple_db.prg
```

Результат:
- Створюється папка `C:\VFP_Lab7`
- Створюється БД `TktDB_Simple.dbc`
- Створюються 4 таблиці з тестовими даними

### Крок 2: Робота з даними

Після створення БД виконайте:
```foxpro
DO work_with_data.prg
```

Цей скрипт демонструє:
- Перегляд таблиць (BROWSE)
- Фільтрацію даних (SET FILTER)
- Пошук записів (LOCATE)
- Підрахунок записів (COUNT)

### Крок 3: Ручна робота з даними

Спробуйте виконати команди вручну:

```foxpro
* Відкрити БД
SET DEFAULT TO "C:\VFP_Lab7"
OPEN DATABASE TktDB_Simple

* Переглянути станції
USE Stations
BROWSE

* Додати новий запис
APPEND BLANK
REPLACE name WITH "Тернопіль", city WITH "Тернопіль"

* Знайти пасажира
LOCATE FOR lname = "Франко"

* Показати інформацію
? fname, lname, phone

* Фільтр за містом
SET FILTER TO city = "Київ"
GO TOP
BROWSE
```

## Основні команди Visual FoxPro

### Робота з БД
- `CREATE DATABASE` - створити БД
- `OPEN DATABASE` - відкрити БД
- `CLOSE DATABASES` - закрити всі БД

### Робота з таблицями
- `CREATE TABLE` - створити таблицю
- `USE` - відкрити таблицю
- `BROWSE` - переглянути дані в табличному вигляді
- `CLOSE TABLES` - закрити таблиці

### Робота з записами
- `APPEND BLANK` - додати новий порожній запис
- `REPLACE` - змінити значення полів
- `DELETE` - позначити запис для видалення
- `RECALL` - відновити позначений запис
- `PACK` - фізично видалити позначені записи

### Навігація
- `GO TOP` - на перший запис
- `GO BOTTOM` - на останній запис
- `SKIP` - до наступного запису
- `SKIP -1` - до попереднього запису
- `GO 5` - до 5-го запису

### Пошук та фільтрація
- `LOCATE FOR` - знайти запис
- `CONTINUE` - продовжити пошук
- `SET FILTER TO` - встановити фільтр
- `SET FILTER TO` (без умови) - скасувати фільтр

### Статистика
- `COUNT` - підрахувати кількість записів
- `SUM` - сума значень
- `AVERAGE` - середнє значення

## Завдання для самостійної роботи

1. Додайте 3 нові станції до таблиці Stations
2. Додайте себе як пасажира до таблиці Passengers
3. Створіть фільтр для відображення маршрутів коротших за 300 км
4. Знайдіть пасажира з прізвищем "Українка" та виведіть його дані
5. Підрахуйте загальну місткість всіх типів вагонів

## Вимоги

- Visual FoxPro 6.0 або новіша версія
- Windows (для шляхів `C:\VFP_Lab7`)

## Примітки

- Всі дані використовують українську кодування CP1251
- Формат дати встановлено на GERMAN (дд.мм.рррр)
- `SET SAFETY OFF` дозволяє перезапис файлів без підтвердження
- Після виконання скриптів БД залишається відкритою для експериментів
