* =========================================
* Текстове представлення меню mainmenu.mnx
* Для створення реального меню відкрийте це в Visual FoxPro
* Menu -> New Menu -> Quick Menu
* =========================================

* Структура меню:
*
* FILE
*   ├── Exit
*
* SEARCH
*   ├── Послідовний пошук

* =========================================
* КОД ДЛЯ МЕНЮ (для введення в Menu Designer)
* =========================================

* Для пункту FILE -> Exit:
* Command: THISFORM.Release()

* Для пункту SEARCH -> Послідовний пошук:
* Command: DO FORM forms\searchform.scx
