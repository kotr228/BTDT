## ЧАСТИНА 1: СТВОРЕННЯ ПРОЕКТУ

### Крок 1: Створення нового проекту

1. Запустіть **Visual FoxPro 9.0**
2. Натисніть **File → New...**
3. Виберіть **Project**
4. Натисніть **New File**
5. Збережіть як: `Lab7.pjx` у папці `Lab7_FoxPro`

### Крок 2: Налаштування проекту

1. Проект відкриється у Project Manager
2. Встановіть робочу директорію:
   ```
   File → Set Default Directory
   Виберіть: Lab7_FoxPro\
   ```

## ЧАСТИНА 2: СТВОРЕННЯ БАЗИ ДАНИХ

### Крок 19: Додавання коду до форми пошуку

#### Метод Init:
```foxpro
IF !USED("customer")
    IF FILE("data\customer.dbf")
        USE data\customer IN 0 SHARED
    ELSE
        USE customer IN 0 SHARED
    ENDIF
ENDIF

SELECT customer

THISFORM.cboField.AddItem("lastname - Прізвище")
THISFORM.cboField.AddItem("firstname - Ім'я")
THISFORM.cboField.AddItem("phone - Телефон")
THISFORM.cboField.AddItem("email - Email")
THISFORM.cboField.AddItem("address - Адреса")
THISFORM.cboField.ListIndex = 1

GO TOP
THISFORM.grdCustomer.Refresh()

RETURN .T.
```

#### Метод Click кнопки btnSearch:
```foxpro
LOCAL lcSearchValue, lcFieldName, llFound

lcSearchValue = ALLTRIM(THISFORM.txtSearch.Value)

IF EMPTY(lcSearchValue)
    MESSAGEBOX("Введіть текст для пошуку!", 48, "Увага")
    THISFORM.txtSearch.SetFocus()
    RETURN
ENDIF

lcFieldName = LEFT(THISFORM.cboField.Value, AT("-", THISFORM.cboField.Value) - 1)
lcFieldName = ALLTRIM(lcFieldName)

SELECT customer
GO TOP

* Послідовний пошук
llFound = .F.
SCAN
    lcFieldValue = EVALUATE("customer." + lcFieldName)
    IF VARTYPE(lcFieldValue) != "C"
        lcFieldValue = TRANSFORM(lcFieldValue)
    ENDIF

    IF !THISFORM.chkCaseSensitive.Value
        lcFieldValue = UPPER(ALLTRIM(lcFieldValue))
        lcSearchValue = UPPER(ALLTRIM(lcSearchValue))
    ENDIF

    IF lcSearchValue $ lcFieldValue
        llFound = .T.
        EXIT
    ENDIF
ENDSCAN

IF llFound
    THISFORM.btnSearchNext.Enabled = .T.
    THISFORM.lblInfo.Caption = "Знайдено запис №" + TRANSFORM(RECNO())
    THISFORM.lblInfo.ForeColor = RGB(0,128,0)
ELSE
    MESSAGEBOX("Запис не знайдено!", 48, "Результат")
    THISFORM.lblInfo.Caption = "Запис не знайдено"
    THISFORM.lblInfo.ForeColor = RGB(255,0,0)
    GO TOP
ENDIF

THISFORM.grdCustomer.Refresh()
```

#### Метод Click кнопки btnSearchNext:
```foxpro
LOCAL lcSearchValue, lcFieldName, llFound

lcSearchValue = ALLTRIM(THISFORM.txtSearch.Value)
lcFieldName = LEFT(THISFORM.cboField.Value, AT("-", THISFORM.cboField.Value) - 1)
lcFieldName = ALLTRIM(lcFieldName)

SELECT customer
SKIP 1

IF EOF()
    MESSAGEBOX("Досягнуто кінця таблиці", 48, "Інформація")
    GO BOTTOM
    RETURN
ENDIF

* Продовжуємо пошук
llFound = .F.
SCAN
    lcFieldValue = EVALUATE("customer." + lcFieldName)
    IF VARTYPE(lcFieldValue) != "C"
        lcFieldValue = TRANSFORM(lcFieldValue)
    ENDIF

    IF !THISFORM.chkCaseSensitive.Value
        lcFieldValue = UPPER(ALLTRIM(lcFieldValue))
        lcSearchValue = UPPER(ALLTRIM(lcSearchValue))
    ENDIF

    IF lcSearchValue $ lcFieldValue
        llFound = .T.
        EXIT
    ENDIF
ENDSCAN

IF llFound
    THISFORM.lblInfo.Caption = "Знайдено запис №" + TRANSFORM(RECNO())
    THISFORM.lblInfo.ForeColor = RGB(0,128,0)
ELSE
    MESSAGEBOX("Більше збігів немає!", 48, "Результат")
    THISFORM.lblInfo.Caption = "Більше збігів немає"
    THISFORM.lblInfo.ForeColor = RGB(255,128,0)
ENDIF

THISFORM.grdCustomer.Refresh()
```
