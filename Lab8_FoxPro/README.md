# Лабораторна робота №8 - Visual FoxPro

## Опис

Проміжна лабораторна робота - створення графічних форм для перегляду даних з бази даних Lab7.

## Мета роботи

- Навчитися створювати форми у Visual FoxPro
- Освоїти роботу з компонентами Grid для відображення даних
- Реалізувати простий пошук та фільтрацію даних у формах
- Навчитися працювати з подіями форм та кнопок

## Взаємозв'язок з Lab7

Ця лабораторна робота **витікає з Lab7**:
- Використовує БД `TktDB_Simple.dbc`, створену в Lab7
- Додає графічний інтерфейс для роботи з даними
- Готує до Lab9 з повноцінною системою редагування

**Послідовність виконання:** Lab7 → Lab8 → Lab9

## Створювані форми

### 1. frm_main_menu.scx - Головне меню
Центральна форма з навігацією:
- Кнопка "Перегляд станцій"
- Кнопка "Перегляд пасажирів"
- Кнопка "Перегляд маршрутів"
- Кнопка "Вихід"

**Компоненти:**
- Label (заголовок)
- 4 CommandButton

### 2. frm_stations.scx - Перегляд станцій
Форма для перегляду всіх залізничних станцій:
- Відображення станцій у Grid (тільки для читання)
- Відображення всіх полів: ID, назва, місто, область

**Компоненти:**
- Label (заголовок)
- Grid (прив'язаний до таблиці Stations)
- CommandButton (закрити)

### 3. frm_passengers.scx - Перегляд пасажирів з пошуком
Форма для перегляду пасажирів з можливістю пошуку:
- Відображення пасажирів у Grid
- Пошук за прізвищем (LOCATE)
- Повідомлення про результат пошуку

**Компоненти:**
- Label (заголовок, мітка пошуку)
- TextBox (введення прізвища)
- CommandButton (пошук, закрити)
- Grid (прив'язаний до таблиці Passengers)

**Функціонал пошуку:**
```foxpro
LOCATE FOR UPPER(ALLTRIM(lname)) = UPPER(ALLTRIM(введене_значення))
IF FOUND()
    MESSAGEBOX("Пасажира знайдено!")
ELSE
    MESSAGEBOX("Пасажира не знайдено")
ENDIF
```

### 4. frm_routes.scx - Перегляд маршрутів з фільтром
Форма для перегляду маршрутів з фільтрацією:
- Відображення маршрутів у Grid
- Фільтр за відстанню (більше N км)
- Кнопки "Застосувати" та "Скасувати" фільтр

**Компоненти:**
- Label (заголовок, мітка фільтра)
- TextBox (введення мінімальної відстані)
- CommandButton (застосувати, скасувати, закрити)
- Grid (прив'язаний до таблиці Routes)

**Функціонал фільтрації:**
```foxpro
* Застосувати фільтр
SET FILTER TO distance > введене_значення
GO TOP

* Скасувати фільтр
SET FILTER TO
GO TOP
```

## Технічні особливості

### DataSession
Всі форми використовують `DataSession = 2` (Private DataSession):
- Ізоляція даних між формами
- Кожна форма має свою робочу область
- Запобігає конфліктам при одночасній роботі кількох форм

### Відкриття БД в події Load
```foxpro
.WriteMethod("Load",
    [SET EXCLUSIVE OFF] + CHR(13) +
    [SET DEFAULT TO "C:\VFP_Lab7"] + CHR(13) +
    [OPEN DATABASE "TktDB_Simple" SHARED] + CHR(13) +
    [USE Passengers IN 0 SHARED])
```

**Чому в Load, а не в Init?**
- Grid потребує відкритих таблиць при ініціалізації
- Load виконується перед Init компонентів
- Запобігає помилкам "Alias not found"

### Grid у режимі ReadOnly
Всі Grid мають `ReadOnly = .T.`:
- Тільки перегляд даних (без редагування)
- Безпека даних для початківців
- Підготовка до Lab9 з повноцінним редагуванням

### Прив'язка Grid до таблиці
```foxpro
.grdStations.RecordSourceType = 1  && Alias
.grdStations.RecordSource = "Stations"
```

## Основні концепції Visual FoxPro Forms

### Створення форм програмно
```foxpro
CREATE FORM form_name NOWAIT
ASELOBJ(laForm, 1)
loForm = laForm[1]
```

### Додавання компонентів
```foxpro
.AddObject("cmdButton", "CommandButton")
.cmdButton.Caption = "Натисни мене"
.cmdButton.Top = 50
.cmdButton.Left = 50
.cmdButton.Visible = .T.
```

### Запис методів
```foxpro
.cmdButton.WriteMethod("Click", "MESSAGEBOX('Клік!')")
```

### Події форм
- **Load** - завантаження форми (відкриття БД)
- **Init** - ініціалізація компонентів
- **Destroy** - закриття форми (очищення)
