# Лабораторна робота №9 - Visual FoxPro

## Опис

Повноцінна система управління залізничними квитками у Visual FoxPro з редагуванням, пошуком за індексами та SQL-запитами.

## Взаємозв'язок з попередніми роботами

Ця лабораторна робота **витікає з Lab8**:
- Lab7 → Lab8 → **Lab9**
- Lab7: Створення простої БД
- Lab8: Додавання форм для перегляду даних
- Lab9: Повноцінна система з редагуванням, пошуком та запитами

**Відмінності від Lab8:**
- Нормалізована БД з 11 таблицями (замість 4)
- Форми з можливістю редагування даних (APPEND, DELETE)
- PageFrame з кількома вкладками
- Пошук за індексами (SEEK замість LOCATE)
- SQL-запити з курсорами

## Структура проекту

- `create_db.prg` - скрипт створення БД та наповнення даними
- `create_forms.prg` - скрипт створення форм для роботи з БД

## База даних TktDB_Norm

Нормалізована база даних містить наступні таблиці:

### Довідкові таблиці
- **CarTypes** - типи вагонів (Плацкарт, Купе, Люкс, Сидячий)
- **Stations** - залізничні станції

### Основні таблиці
- **Passengers** - інформація про пасажирів (прізвище, ім'я, по батькові)
- **Address** - адреси пасажирів (дім, робота, дача)
- **PhoneNums** - телефонні номери пасажирів
- **Routes** - маршрути між станціями
- **Schedules** - розклад руху потягів
- **Trips** - конкретні поїздки за датами
- **Cars** - вагони у поїздках
- **Seats** - місця у вагонах
- **Reserv** - бронювання та квитки

## Форми

Система містить 4 форми:

1. **frm_menu.scx** - головне меню з кнопками:
   - База Даних
   - Пошук
   - Запити та Перегляди

2. **frm_data.scx** - форма редагування даних:
   - Вкладка "Станції" - перегляд та редагування станцій
   - Вкладка "Пасажири" - перегляд та редагування пасажирів

3. **frm_search.scx** - форма пошуку:
   - Пошук пасажирів за ID з використанням індексів

4. **frm_queries.scx** - форма запитів:
   - Виконання SQL-запитів до БД
   - Перегляд розкладу руху потягів

## Використання

### Крок 1: Створення БД

У Visual FoxPro виконайте:
```foxpro
DO create_db.prg
```

Це створить:
- Папку `C:\VFP_Lab9`
- Базу даних `TktDB_Norm.dbc`
- Всі таблиці з тестовими даними

### Крок 2: Створення форм

Після створення БД виконайте:
```foxpro
DO create_forms.prg
```

Це створить файли форм:
- `frm_menu.scx` / `frm_menu.sct`
- `frm_data.scx` / `frm_data.sct`
- `frm_search.scx` / `frm_search.sct`
- `frm_queries.scx` / `frm_queries.sct`

### Крок 3: Запуск додатку

Запустіть головне меню:
```foxpro
DO FORM frm_menu
```

## Особливості реалізації

### Виправлення Grid

Скрипт `create_forms.prg` містить виправлення для коректного відображення даних у Grid:

- Таблиці відкриваються в події `Load` форми (до ініціалізації Grid)
- Використовується `DataSession = 2` (Private DataSession) для ізоляції даних
- `RecordSourceType = 1` (Alias) для прямого зв'язку з таблицями

### Зв'язки між таблицями

База даних використовує нормалізовану структуру з реляційними зв'язками:
- Зовнішні ключі (REFERENCES) для забезпечення цілісності даних
- Автоінкремент (AUTOINC) для первинних ключів
- Індекси для швидкого пошуку

## Тестові дані

БД містить тестові дані про:
- 5 типів вагонів
- 5 залізничних станцій
- 5 пасажирів (відомі українські письменники)
- 5 маршрутів між містами України
- 5 розкладів руху потягів
- Відповідні поїздки, вагони, місця та квитки
